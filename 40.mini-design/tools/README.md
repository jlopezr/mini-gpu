# Herramientas

Conversores en Python 3 de los recursos de NewsMaster. Make los lanza solos;
la documentación completa está en [`docs/`](../docs/README.md).

| Herramienta | Convierte | Documentación |
|---|---|---|
| [`flb2mf.py`](flb2mf.py) | `NEWS.FLB` → fuentes `.mf` (y hojas PNG con Pillow) | [minifont.md](../docs/minifont.md) |
| [`bdf2mf.py`](bdf2mf.py) | Fuentes BDF → `.mf` | [minifont.md](../docs/minifont.md) |
| [`shp2png.py`](shp2png.py) | Ilustraciones `NEWS.SHP` → PNG (Pillow) | [newsmaster.md](../docs/newsmaster.md) |
| [`icn2png.py`](icn2png.py) | Iconos `NEWS.ICN` → PNG (Pillow) | [newsmaster.md](../docs/newsmaster.md) |
