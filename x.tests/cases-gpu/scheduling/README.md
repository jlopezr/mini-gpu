# Planificación de warps

| Caso | Qué valida |
|---|---|
| [independent-pcs](independent-pcs/) | Cada warp mantiene su PC y su contador propios |
| [workgroup-barriers](workgroup-barriers/) | Dos grupos de trabajo con `BAR` y máscaras parciales |
| [barrier-finished-warp](barrier-finished-warp/) | Un warp terminado no bloquea la barrera |
| [workgroup-barrier-isolation](workgroup-barrier-isolation/) | Una `BAR` solo espera a su grupo (si no, se cuelga) |
