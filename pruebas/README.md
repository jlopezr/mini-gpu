# Pruebas históricas

Esta carpeta conserva artefactos temporales o versiones archivadas que no
forman parte del flujo activo del proyecto. `7.fpga-ram.tgz` corresponde a una
copia histórica de una prueba de SDRAM.

Para trabajar con el controlador vigente deben usarse las carpetas
`7.ulx3s_w9825g6kh_test`, `8.fpga-ram`, `9.fpga-ram-param` y
`10.fpga-cpu-ram`. El archivo se mantiene únicamente como referencia y no es
una dependencia de construcción.
